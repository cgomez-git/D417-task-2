PASSLIB SETUP FOR ANSIBLE PASSWORD HASHING 
step 1:

sudo apt update

step 2: Install the virtual environment module

sudo apt install python3.12-venv --fix-missing

step 3: set the current directory as a virtual environment

python3 -m venv .

step 4: Activate the virtual environment

sources ./bin/activate

step 5: Upgrade pip

python3 -m pip install --upgrade pip

step 6: Install the Passlib module

python3 -m pip install passlib
